# I-MOBI expandido

Abra `index.html` para a página institucional ou `index2.html` para entrar diretamente na experiência do cliente.

## Novas áreas do cliente

- `buscar-imoveis.html`: resultados com filtros e ordenação.
- `imovel.html`: galeria, dados do imóvel, corretora e agendamento.
- `favoritos.html`: lista de imóveis salvos.
- `agendamentos.html`: visitas futuras e concluídas.
- `mensagens.html`: central de conversas.
- `perfil.html` e `configuracoes.html`: conta, preferências e segurança.
- `ajuda.html`, `sobre.html`, `privacidade.html` e `termos.html`: conteúdo de suporte e institucional.
- `corretor.html`: painel independente para o corretor.

## Arquivos compartilhados

- `portal.css`: identidade visual e responsividade das páginas novas.
- `portal.js`: favoritos locais, galeria de imagens, buscas e interações de demonstração.

O projeto usa HTML, CSS e JavaScript puro. Não há dependências de bibliotecas de interface.
